# กติกาและหน้าจอฉบับปรับปรุง 30 ตุลาคม 2026

เอกสารนี้แทนที่กติกาที่ขัดกันใน ADR 0004 และรายงานรอบก่อน

- กระดานแรกของบัญชีใช้ชุดเริ่มต้นร่วมกัน ไม่เรียก AI: 12 ภารกิจง่าย / 8 กลาง / 4 ท้าทาย และช่องบริจาคกลางกระดาน
- ตั้งแต่กระดานที่สอง ส่งสถิติการใช้จ่ายย้อนหลัง 30 วันรวมวันนี้และประวัติภารกิจให้ AI เลือกภารกิจ Server ตรวจรหัส เป้าหมาย และจัดระดับตามข้อมูลจริงโดยรักษาสัดส่วน 12/8/4 ไม่มีเงื่อนไขต้องมี 5 ธุรกรรมก่อน
- ถ้าไม่มีคีย์หรือ AI ล้มเหลว ใช้กฎสำรองและแสดง RULE_BASED ตามจริง การทดสอบผ่าน mock ยืนยันการเชื่อมต่อและการรับมือข้อผิดพลาด ไม่ใช่การประเมินคุณภาพโมเดลจริง
- โบนัสแถว = 20 + (ผลรวมระดับความยาก 5 ช่อง × 4) โดยบริจาคคิดระดับ 3 กระดานใหม่จัดให้ทุกคนมีโอกาสโบนัสสูงสุด 68 เท่ากัน ตำแหน่งและภารกิจของกระดานส่วนบุคคลสลับได้ รับโบนัสได้หนึ่งเส้นต่อกระดานเหมือนเดิม
- กระดานเดิมอัปเกรดเฉพาะภารกิจที่ยังไม่สำเร็จ ไม่ลบประวัติหรือโทเค็น และเก็บโบนัสที่จ่ายแล้วตามยอดเดิม
- POST /api/v1/quests/demo-complete ต้องล็อกอิน เลือก position หรือ lineId ของกระดานตนเองเท่านั้น ตรวจสถานะและล็อกผู้ใช้ใน transaction ป้องกันแจกซ้ำ ช่องทดสอบติด demo_completed และไม่นำมาเป็นพฤติกรรมสำเร็จให้ AI ไม่มีธุรกรรมใช้จ่ายหรือบริจาคปลอม
- เครื่องมือทดสอบเปิดเฉพาะโหมดสาธิตและไม่ใช่ production โดยปริยาย ปิดได้ด้วย ENABLE_DEMO_TOOLS=false; production ต้องระบุ true จึงเปิด ส่วน endpoint /quests/progress เดิมยังปิด
- หน้า Bingo มีโทเค็นและเป้าหมายทุกช่อง เส้นขีดเมื่อบิงโก และปุ่มทดสอบทั้งรายช่องในรายละเอียดกับแถว 1 ใต้เครื่องมือทดสอบ
- มูลนิธิใช้ภาพปกเต็มการ์ด 2 คอลัมน์บนจอใหญ่ มีภาพจากองค์กร 6 แห่ง ส่วนที่เหลือใช้ภาพประกอบหมวดหมู่พร้อมป้ายแยกชัดเจน
- ภาพทั้งหมดเก็บใน frontend/public/assets ภาพที่ดาวน์โหลดกับไฟล์ที่ผู้ใช้อัปโหลดแสดงผลด้วยหลักเดียวกัน การเก็บในโปรเจกต์ช่วยไม่ให้พึ่ง hotlink ภายนอก
- รางวัลลุ้นแยกเป็นทองคำแท่ง / iPhone 18 Pro / Honda Scoopy เลือกแพ็ก 1/3/5 สิทธิ์ได้ บันทึก reward_id ของรางวัลที่เลือกในประวัติจริง และมีคูปอง กระเป๋าผ้า แก้วเซรามิกพร้อมภาพ
- หน้าหลักแทนเมนูลัดซ้ำ Navbar ด้วยประวัติการให้ล่าสุด

## ภาพและแหล่งข้อมูล

ดู [รายการไฟล์และแหล่งต้นฉบับ](media-manifest-v3.json) ภาพองค์กรและสินค้ายังคงเป็นของเจ้าของ ใช้ประกอบโครงงานสาธิต ไม่ได้แสดงความร่วมมือกับองค์กรหรือผู้ผลิต ภาพ Rama banner ไม่ใช้บนหน้าจอเพราะมีข้อความแคมเปญเฉพาะ ใช้ภาพประกอบสุขภาพและโลโก้แทน

## ตรวจสอบซ้ำ

รัน npm test และ npm run verify:app ใน backend และ npm run build ใน frontend สคริปต์ verify:app ใช้ฐานข้อมูลทดสอบแยกและลบเฉพาะฐานนั้นเมื่อจบ ดูผลล่าสุดที่ docs/qa/functional-report.json

ผลตรวจรอบนี้: unit tests 46 ผ่าน, functional/browser checks 20 ผ่าน, AI adapter ผ่าน 4 สถานการณ์ด้วย Postman simulation, production build ผ่าน, lint ไม่มี error แต่ยังมีคำเตือน React 8 จุดในชุดหน้าเดิมและหน้าที่เกี่ยวข้อง ไม่ได้เรียก AI ด้วยคีย์จริงระหว่างทดสอบ
