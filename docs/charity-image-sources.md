# ที่มาของภาพมูลนิธิ

ตรวจชื่อและเว็บไซต์ทางการวันที่ 30 ตุลาคม 2026 ใช้ตราสัญลักษณ์เพื่อระบุชื่อในโครงงานการศึกษา ไม่ใช่ภาพที่สร้างด้วย AI และไม่แสดงว่าเป็นพันธมิตรหรือได้รับการรับรอง เว็บไซต์ในตารางเปิดได้จากการ์ดมูลนิธิ

| ชื่อ | เว็บไซต์ทางการ | ไฟล์ต้นทาง | ไฟล์ที่ใช้ |
|---|---|---|---|
| มูลนิธิยุวพัฒน์ | https://www.yuvabadhanafoundation.org/th/home/ | https://www.yuvabadhanafoundation.org/wp-content/uploads/2023/09/logo-ybf@2x.png | frontend/public/assets/charities/yuvabadhana.png |
| มูลนิธิสืบนาคะเสถียร | https://www.seub.or.th/ | https://www.seub.or.th/seubweb/wp-content/uploads/2018/01/logo.png | frontend/public/assets/charities/seub.png |
| มูลนิธิกระจกเงา | https://www.mirror.or.th/ | https://www.mirror.or.th/images/logom_top.png | frontend/public/assets/charities/mirror.png |
| มูลนิธิรามาธิบดี | https://www.ramafoundation.or.th/ | https://www.ramafoundation.or.th/assets/images/logomain.png | frontend/public/assets/charities/ramathibodi.png |

โลโก้เป็นทรัพย์สินขององค์กรต้นทาง ไม่ได้อ้างว่าเป็น public domain ก่อนเผยแพร่นอกบริบทการศึกษาต้องพิจารณาสิทธิ์การใช้ของเจ้าของ ชื่ออื่นใน seed ใช้ไอคอนหมวดหมู่จาก lucide-react ไม่จับคู่กับโลโก้ที่ยังตรวจไม่ตรงชื่อ เลขภาษีและสถานะการลดหย่อนใน seed เดิมยังไม่ได้ตรวจยืนยันและไม่ใช้แสดงสิทธิ์ลดหย่อนใน UI


รอบภาพปกเต็มการ์ด: ดู [manifest v3](media-manifest-v3.json) และ [กติกาล่าสุด](project-refinements-v3.md) ภาพประกอบหมวดหมู่ระบุบนการ์ด ไม่อ้างว่าเป็นภาพกิจกรรมขององค์กรนั้น
